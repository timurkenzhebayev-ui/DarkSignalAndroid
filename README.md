# ТЁМНЫЙ СИГНАЛ — Dark Signal

Небольшой атмосферный 3D-хоррор под Android, сделанный без игрового движка: Java + OpenGL ES 2.0.

## Что внутри

- один законченный уровень-лабиринт;
- вид от первого лица, настоящий 3D/OpenGL;
- фонарик, тёмный туман, мерцающий свет, светящиеся объекты;
- атмосферный фоновый гул и звуковые эффекты;
- 3 предохранителя, которые нужно найти;
- после второго просыпается существо и начинает преследование;
- после третьего нужно вернуться к стартовому шлюзу;
- полноценная концовка **CONGRATULATIONS** с временем прохождения;
- смерть и быстрый рестарт;
- управление двумя пальцами: слева движение, справа обзор;
- без рекламы, аккаунтов, сети, камеры, микрофона и геолокации.

Ориентир по прохождению: примерно 3–6 минут в первый раз, в зависимости от того, как быстро разберёшься в лабиринте.

## Управление

- левый палец: виртуальный стик, движение;
- правый палец: свайп, поворот камеры;
- предохранители подбираются автоматически, если подойти близко;
- после 3/3 возвращайся туда, где начал игру.

## Сборка APK через GitHub Actions

Проект уже содержит `.github/workflows/build-apk.yml`.

1. Создай новый пустой GitHub-репозиторий, например `DarkSignalAndroid`.
2. Загрузи туда всё содержимое этой папки, сохранив структуру каталогов.
3. Если браузер пропустил скрытую папку `.github`, создай файл вручную: `.github/workflows/build-apk.yml` и вставь содержимое файла из архива.
4. Открой вкладку **Actions**.
5. После зелёной галочки скачай артефакт **DarkSignal-debug-apk**.
6. Внутри ZIP будет `app-debug.apk`.

## Безопасность

Приложение запрашивает только `VIBRATE`. Интернет-разрешений нет. В проекте нет сторонних библиотек приложения.
